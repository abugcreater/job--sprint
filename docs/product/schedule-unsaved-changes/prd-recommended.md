# 个人日程未保存修改保护推荐方案

日期：2026-07-30

## 用户结果

用户在创建或编辑个人日程时，不会因点击另一条日程的编辑按钮或“取消编辑”而静默丢失本次输入；可以继续编辑或明确放弃。

## 最小实现

1. 打开已有日程或创建空白日程时，复制 `CoachScheduleDraft` 作为基线。
2. 比较标识、标题、日期、开始、结束、类型、原因和证据要求。
3. 有修改时显示 `alertdialog`；继续编辑只关闭确认，放弃才执行原动作。
4. 保存成功、删除当前正在编辑的日程、画像或日期变化时更新基线。
5. 确认出现前不写入个人日程，也不改变今日页行动。

## 验收条件

- 新建日程填写内容后编辑另一条日程，先出现确认，继续编辑后输入完整保留。
- 放弃新建输入后才加载目标日程的已保存内容。
- 编辑已有日程、修改原因后取消，先出现确认；放弃后回到新增状态且原记录不变。
- 保存更新后立即取消编辑不出现错误确认。
