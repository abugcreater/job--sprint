# 评审与裁决

## 产品视角

共享设备切换账号时，宁可多一次短暂的会话确认，也不能让用户看到上一位用户的求职记录。采用方案 B。

## 技术视角

单一持久化键本身不是服务端越权，但没有 owner reset 会在本地运行时形成客户端串数据风险。用纯函数定义 transition，并由 AppShell 在路由渲染前调用，能避免 React 生命周期竞态扩散。

## UI/UX 视角

门禁页面只保留账号确认、登录或重试这一项下一步，不显示任务、画像、统计或导航中的业务摘要。避免把安全状态做成复杂的错误页。

## QA 视角

至少覆盖：不同 dataScope 重置、相同 dataScope 保留、匿名清空、失败不放行、local/unconfigured 放行；并运行既有 runtime owner 保存防护回归。
