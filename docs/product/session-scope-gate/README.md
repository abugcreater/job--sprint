# 认证会话与本地快照隔离

日期：2026-08-03
状态：开发中

## 需求卡

- 原始问题：React 使用单一浏览器持久化键 `jobSprint.react.v1`。当运行时不可用、切换登录账号或认证请求尚未完成时，旧账号快照可能被读取或短暂展示。
- 目标用户：在共享浏览器或 Android WebView 中切换 Job Sprint 账号的普通求职用户。
- 用户路径：打开应用或完成账号切换 -> 确认当前会话 -> 仅展示该数据域的进度；未登录或无法确认会话时，不展示历史业务数据。
- 影响模块：React `AppShell`、运行态 owner、认证会话、持久化缓存与回归测试。
- 成功反馈：当前账号确认完成后才进入工作台；账号或数据域变化时，本地运行态先按新 owner 重置，再由服务端同步该用户数据。

## 本轮范围

1. 把认证会话转成可比较的运行态 owner，并只在 owner/dataScope 匹配时保留本地快照。
2. 远端认证处于检查、匿名或失败状态时，隐藏业务路由内容，避免旧快照短暂出现。
3. 匿名状态主动清空本地运行态；已认证且 owner 不匹配时切换到新 owner 的空态。
4. 保持无服务端认证的 `local` 与 `unconfigured` 开发/单机模式可正常使用。

## 明确不做

- 不改 Node/Rust 数据库结构、登录协议、远端配置、账号或生产数据。
- 不新增公开注册、组织租户、跨设备离线冲突合并或加密存储。
- 不把网络故障伪装成已认证；会话失败时只显示安全入口，不展示本地业务内容。
