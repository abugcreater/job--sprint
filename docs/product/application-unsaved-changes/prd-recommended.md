# 机会编辑未保存修改保护推荐方案

日期：2026-07-26

## 用户结果

用户修改机会事实后，点击取消或关闭不会悄悄丢失输入：可以继续检查和保存，也可以明确放弃本次修改并回到原来的详情或列表。

## 最小实现

1. 打开新增或编辑器时记录草稿基线，字段与标签都参与比较。
2. 用户未改动时，取消和关闭沿用当前直接退出行为。
3. 用户改动后，取消和关闭先展示模态确认；“继续编辑”不改变草稿和 URL，“放弃修改”才重置草稿并退出编辑器。
4. 保存成功、表单校验失败、删除确认和机会详情行为保持不变。

## 验收条件

- 新增表单修改公司或岗位后取消，会先显示放弃确认；继续编辑后输入仍在。
- 编辑已有记录后修改沟通反馈，点击移动端关闭按钮会先显示放弃确认；放弃后原记录没有被覆盖。
- 未修改时取消不会额外显示确认。
- 所有确认路径不新增 Evidence Gate 记录，不调用同步，不改变当前用户数据域。
