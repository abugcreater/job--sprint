# 方案比较

## 问题

面试薄弱题标记原先固定写入一个浏览器键。相同设备上切换账号时，两个账号可能因相同候选题 ID 看到彼此的练习偏好。

| 方案 | 好处 | 风险 | 结论 |
|---|---|---|---|
| A. 继续共享本机标记 | 无改造成本 | 与数据域隔离承诺冲突，新用户会被旧标记误导 | 不采用 |
| B. 按 `dataScope` 分桶，旧 key 不迁移 | 隔离直接、无需服务端，未知历史数据不会误归属 | 已登录账号首次升级后不会继承旧标记 | 推荐 |
| C. 直接同步为服务端数据 | 可跨设备保留 | 扩大数据模型、权限、Node/Rust 合同与删除语义，超出本轮 | 延期 |

## 裁决原则

练习偏好可以本地保存，但没有可验证归属的数据不得进入认证账号。正式证据仍仅由用户点击保存后写入。
