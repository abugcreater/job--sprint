# 未保存内容路由离开保护审阅与裁决

日期：2026-08-01

## 事实审阅

- `apps/react-web/src/app/router.tsx` 使用 `HashRouter`，不是 data router；不能直接采用 `useBlocker`。
- `AppShell` 的侧栏、移动底栏以及多个页面 CTA 都是 React Router `Link` / `NavLink`，跳转会卸载当前页面。
- 画像、知识边界、日程、机会、复盘只对各自局部取消或替换动作做了草稿基线比较，跨页面跳转没有共同入口。
- 当前草稿保存前不应写入正式记录，这是既有产品合同。

## 裁决

采用 AppShell 级统一保护作为当前可验证增量：站内导航使用产品内确认，浏览器整页离开使用标准浏览器确认。

不采用 history 回退/重复 pushState 的方式劫持系统返回。它会在 HashRouter 与 Android WebView 的历史栈上引入重复记录、回退循环和无法证明的恢复语义。系统返回、应用强杀与跨设备恢复继续作为后续 Android/草稿产品需求处理。

## 风险控制

- Provider 只保存布尔检查回调，不保存表单内容，避免引入跨域读取。
- 每个页面卸载会注销回调，避免旧页面污染新路由。
- 浏览器原生提示不承诺显示定制文案，这是浏览器安全限制。
