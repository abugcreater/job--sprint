# 未保存内容路由离开保护推荐方案

日期：2026-08-01

## 用户体验

1. 用户修改画像、知识边界、日程、机会或复盘任一表单。
2. 点击任一站内模块链接时，应用不立即切页，而是提示“离开当前页面？”。
3. 选择“继续编辑”保留输入并回到原链接焦点；选择“放弃修改并离开”才执行原路由跳转。
4. 刷新、关闭页签、跳转到登录等整页离开由浏览器显示标准提示。
5. 未修改时不增加任何额外交互。

## 实现边界

- `RouteLeaveGuardProvider` 位于 `AppShell`，维护当前页面注册的 dirty 回调。
- `useRouteLeaveGuard(isDirty)` 只负责注册状态，不直接改表单数据。
- Provider 只拦截当前 React 应用的 `#/...` 链接；其它外部链接由 `beforeunload` 覆盖。
- 确认“放弃”不执行保存、删除、同步、AI 反馈或权限操作；路由卸载的原有行为才会丢弃内存草稿。

## 验收标准

- 脏草稿点击站内链接不改变路由，显示确认面板。
- 继续编辑后路由与输入保持不变。
- 确认放弃后跳转到目标路由。
- 无脏草稿不显示确认，链接可直接跳转。
- 脏草稿触发 `beforeunload` 时会阻止浏览器直接离开。
