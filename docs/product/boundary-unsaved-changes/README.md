# 知识边界未保存修改保护

日期：2026-07-31
状态：已完成（本地 React 验收）

## 需求卡

- 原始问题：用户新建或编辑知识边界后点击另一条边界的编辑、取消编辑，草稿会被静默替换或清空；点击“修订后编辑”AI 候选还会提前删除候选并记录反馈。
- 目标用户：正在把 JD、简历和面试反馈沉淀成真实知识边界的普通用户。
- 用户路径：新建或编辑边界 -> 修改字段 -> 编辑另一条、取消编辑或修订 AI 候选 -> 继续编辑或明确放弃修改。
- 影响模块：React 教练页知识边界、AI 候选修订流、局部草稿适配层、确认面板、页面测试和产品运营文档。
- 数据对象：当前 `KnowledgeBoundaryDraft`、AI 候选和候选反馈；确认放弃前不写入正式边界、今日行动、同步层或候选反馈账本。
- 权限与隔离：沿用当前激活画像过滤后的边界与候选反馈；不增加账号能力、不读取其它画像或数据域。
- 成功反馈：未修改维持一步操作；有修改时用户必须选择“继续编辑 / 放弃修改”，AI 候选的修订反馈只在放弃当前草稿后记录。
- 验证层级：草稿单测、React 页面真实交互、类型检查、前端回归、架构质量和敏感扫描。

## 本轮范围

1. 比较 `KnowledgeBoundaryDraft` 的 12 个字段，并保存独立草稿基线。
2. 保护“编辑另一条知识边界”与“取消编辑”的草稿替换入口。
3. 保护“修订后编辑”AI 候选：确认前保留候选，不记录 `needs_revision` 反馈。
4. 保存成功、删除当前编辑边界、切换画像或日期后刷新基线；未修改保持快速路径。

## 明确不做

- 不拦截浏览器刷新、关闭标签页、外部路由、Android 系统返回或应用强杀。
- 不保护采纳、拒绝、删除另一条边界和其它表单的离开动作，也不建立全局草稿协议。
- 不自动保存、不增加服务端草稿、不修改 Android 包、服务器或远端配置。
