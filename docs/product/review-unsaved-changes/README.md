# 复盘编辑未保存修改保护

日期：2026-07-29
状态：已完成（本地 React 验收）

## 需求卡

- 原始问题：用户编辑已有本地复盘后点击“取消编辑”，当前实现会直接清空草稿，刚补充的结果、卡点和明日优先级无法恢复。
- 目标用户：正在把当天求职行动沉淀到 Evidence Gate 的普通用户。
- 用户路径：复盘历史 -> 编辑本机复盘 -> 修改字段 -> 取消编辑 -> 继续编辑或明确放弃修改。
- 影响模块：React 复盘页、复盘草稿适配层、局部确认面板、页面测试和产品运营文档。
- 数据对象：仅当前 `ReviewFormDraft` 与内存基线；确认放弃前不更新或删除 Evidence Gate，也不调用同步或服务器结果快照。
- 权限与隔离：沿用当前登录会话和当前用户的 Evidence Gate 记录；不增加账号能力、不读取其它数据域。
- 成功反馈：未修改时仍直接取消编辑；有修改时可选择“继续编辑 / 放弃修改”，前者保留全部输入，后者才离开编辑状态并恢复空白新增草稿。
- 验证层级：草稿适配层单测、React 页面测试、类型检查、前端回归、产品治理和敏感扫描。

## 本轮范围

1. 为复盘草稿提供克隆与精确 dirty 判断，覆盖全部六个可编辑字段。
2. 编辑已有本地复盘时记录已保存基线。
3. “取消编辑”遇到未保存修改时显示局部确认；保存成功后重置基线。
4. 覆盖继续编辑、放弃修改、未修改快速取消和确认前不写入 Evidence Gate 的回归测试。

## 明确不做

- 不保护浏览器刷新、关闭标签页、外部路由、Android 系统返回或应用强杀。
- 不阻止编辑另一条复盘、删除复盘或切换复盘工作区视图；这些动作需要单独的行为与焦点设计。
- 不建立覆盖画像、知识边界、日程和复盘的全局表单协议。
- 不自动保存、不增加服务端草稿、不修改 Android 包或服务器配置。
