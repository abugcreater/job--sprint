# 复盘编辑未保存修改保护推荐方案

日期：2026-07-29

## 用户结果

用户更新一条本机复盘时，点击取消不会静默丢失刚补充的事实、卡点和明日行动；可以继续修改或明确放弃本次输入。

## 最小实现

1. 在打开已有本机复盘时复制 `ReviewFormDraft` 作为基线。
2. 比较项目结果、面试题、知识点、路径问题、薄弱回答和明日优先级。
3. 未修改时直接取消；有修改时显示 `alertdialog`。
4. “继续编辑”只关闭确认；“放弃修改”才清空草稿、退出编辑状态并保留原 Evidence Gate 记录。
5. 保存成功后清空草稿与基线，维持既有“更新复盘”行为。

## 验收条件

- 编辑已有复盘、改写路径问题后取消，先出现确认；继续编辑后输入仍在。
- 放弃修改后回到新增复盘状态，历史记录仍保留保存前内容。
- 未修改时取消不显示确认。
- 保存后再取消不会出现错误确认，也不会额外写入 Evidence Gate。
