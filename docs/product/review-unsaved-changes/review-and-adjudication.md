# 复盘编辑未保存修改保护审阅与裁决

日期：2026-07-29

## 已确认事实

- `ReviewPage.handleCancelEdit` 直接执行 `setEditingRecord(null)` 和 `setDraft(createReviewDraft())`。
- 复盘编辑保存会更新现有 Evidence Gate 记录；取消前的草稿不应覆盖或删除该记录。
- 当前复盘页只有编辑态才展示“取消编辑”，因此局部确认可以精确覆盖该已证实入口。

## 裁决

采用方案 B。草稿比较与基线放入独立复盘模块；页面只请求取消或执行已经确认的取消，避免把六个字段判断散落在 JSX 中。

## 安全与边界

- 确认面板不得保存、更新、删除或恢复 Evidence Gate，不调用服务器结果快照或同步。
- 只比较当前用户当前页面的内存草稿，不读取其它用户或数据域。
- 其它离开行为没有被本轮覆盖，不能宣传成全局草稿保护。
