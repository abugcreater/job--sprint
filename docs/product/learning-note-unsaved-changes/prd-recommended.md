# 推荐方案

## 用户路径

1. 用户在当前知识任务点击“补学习笔记”。
2. 草稿为空时，点击取消立即关闭，不增加额外打扰。
3. 草稿含有非空内容时，点击取消显示确认弹窗。
4. 选择“继续编辑”保留原文本；选择“放弃修改”才关闭并清空草稿。
5. 草稿存在时，切到其他页面或使用浏览器历史返回，进入已有的全局离页确认；确认放弃后才发生导航。
6. 点击保存后，仍按原有路径写入当前任务的 Evidence Gate，并关闭草稿。

## 可观察结果

- 用户能明确区分“暂不保存”和“确认丢弃”。
- 无论显式取消还是跨页导航，未保存的笔记都不会悄然消失。
- 只有点击“保存学习笔记”才新增学习笔记证据。
