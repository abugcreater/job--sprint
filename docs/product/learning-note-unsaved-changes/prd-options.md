# 方案比较

## 问题

学习笔记是创建 Evidence Gate 证据的关键入口。当前表单只要点击“取消”就清空内存草稿，且学习页没有注册路由离开守卫；用户可能在误点取消、导航或浏览器返回后失去已输入内容。

| 方案 | 好处 | 代价与风险 | 结论 |
|---|---|---|---|
| A. 保持直接取消 | 实现最小 | 与“编辑保存有提示”的产品基线不一致，仍会丢失输入 | 不采用 |
| B. 本地确认 + 复用路由离开守卫 | 覆盖显式取消和真实离页；保持现有交互语言 | 不覆盖刷新后的恢复 | 推荐 |
| C. 自动保存到本地或服务端 | 可跨刷新恢复 | 需要草稿版本、清理策略和隐私边界，范围明显扩大 | 暂不采用 |

## 选择原则

本轮优先避免无提示的数据丢失，且不把尚未确认的学习笔记写入 Evidence Gate。方案 B 满足已有产品交互模式并保持证据写入时机不变。
