# 画像未保存修改保护

日期：2026-07-28
状态：已完成，等待 GitFlow 合入

## 需求卡

- 原始问题：详细画像表单中，用户输入后点击“新建画像”、切换已有画像或“编辑当前画像”会直接替换本地草稿，尚未保存的岗位、经验和边界会丢失。
- 目标用户：正在建立或调整个人求职目标的普通用户。
- 用户路径：教练页 -> 详细画像表单 -> 修改字段 -> 请求新建、切换或重新编辑 -> 继续编辑或明确放弃修改。
- 影响模块：React 教练页、画像草稿适配层、画像表单、页面测试和产品运营文档。
- 数据对象：仅当前 `ProfileDraft` 与内存基线；确认放弃前不写入 `userProfiles`、runtime、AI 建议或 Evidence Gate。
- 权限与隔离：沿用当前会话的数据域与画像归属；不增加账号、owner 能力或跨用户读取范围。
- 成功反馈：未修改时动作立即执行；有修改时明确提示“继续编辑 / 放弃修改”，继续编辑保留所有输入，放弃后才执行原始动作。
- 验证层级：适配层单测、React 页面测试、类型检查、前端回归、产品治理和敏感扫描。

## 本轮范围

1. 为画像草稿记录可比较的基线，并覆盖所有画像字段。
2. 为“新建画像、切换已有画像、编辑当前画像”增加未保存修改确认。
3. 保存成功后刷新草稿基线；未修改时保持现有快速路径。
4. 覆盖继续编辑、放弃修改、无修改切换和未写入持久数据的回归测试。

## 明确不做

- 不建立覆盖知识边界、日程、复盘、快速建档向导和其它模块的全局表单协议。
- 不拦截浏览器刷新、关闭标签页、Android 系统返回或全部外部路由跳转。
- 不自动保存、不新增服务端草稿、不修改 Android 包或服务器配置。
