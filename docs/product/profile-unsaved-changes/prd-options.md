# 画像未保存修改保护方案比较

日期：2026-07-28

## 方案 A：仅补一个“取消编辑”按钮

- 优点：改动最少。
- 缺点：当前风险来自新建、切换和重新编辑三个动作，不提供按钮无法阻止已有入口静默丢草稿。
- 结论：不采用。

## 方案 B：画像表单局部基线确认

- 做法：打开或保存画像时记录基线；每次请求替换草稿时比较当前值。存在修改就先展示确认，放弃后再执行原动作。
- 优点：准确覆盖已证实路径，不写入数据，不改变权限边界，能复用机会编辑器的交互语义。
- 缺点：不解决刷新、系统返回和其它表单。
- 结论：推荐。

## 方案 C：全局草稿守卫与自动保存

- 优点：可覆盖更多页面和离页场景。
- 缺点：需要统一每个表单的状态模型、路由拦截、Android 返回策略与恢复语义，风险和验证面显著扩大。
- 结论：本轮不做，作为后续产品级专题评估。
