# 画像未保存修改保护推荐方案

日期：2026-07-28

## 用户结果

用户编辑个人画像后，请求新建、切换或重新编辑不会静默丢失输入：可以继续检查并保存，也可以明确放弃本次修改后执行原来的画像动作。

## 最小实现

1. 在 `ProfileDraft` 打开、保存和确认放弃后维护独立基线。
2. 比较画像名称、角色族、目标岗位、等级、城市、薪资、公司类型、经验、项目证据、不可夸大边界和每日分钟。
3. 未修改时直接执行新建、激活或编辑；有修改时先显示 `alertdialog`。
4. “继续编辑”只关闭确认；“放弃修改”才执行待处理动作，且不写入画像、AI 建议、运行记录或 Evidence Gate。

## 验收条件

- 编辑已保存画像的经验摘要后点击“新建画像”，先显示确认；继续编辑后输入仍在。
- 编辑已保存画像后请求切换另一画像，放弃后才切换，且原画像不会被未保存内容覆盖。
- 有修改后点击“编辑当前画像”，放弃后恢复该画像已保存版本；未修改时不显示确认。
- 保存成功后基线刷新，再切换画像不会出现错误确认。
- 所有确认路径不扩大数据域、不调用同步或 AI 生成。
