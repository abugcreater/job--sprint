# 推荐方案

## 用户路径

1. 已登录用户进入学习工作台，页面以当前 `dataScope` 读取学习重点标记。
2. 用户标记或取消重点时，浏览器只更新当前数据域的键。
3. 同一设备切换到另一账号后，页面重新读取另一数据域的标记，不展示前一账号的状态。
4. 旧全局 key 即使仍留在浏览器中，也不会被认证账号读取。

## 成功标准

- 两个 `dataScope` 的同一知识卡 ID 可分别保存和读取。
- 当前账号的标记操作不覆盖另一账号的标记。
- 旧共享 key 不能成为认证账号的输入。
- 本地离线模式继续可用，并使用明确的 `local` 分桶。

## 状态与边界

- 空状态：当前数据域没有重点时展示正常未标记状态。
- 读取失败：损坏 JSON 按空标记处理，不影响学习工作台。
- 权限：本地偏好不产生管理员能力，也不改变登录权限。
- 删除：取消重点只修改当前数据域的本地偏好。
